🏆 작품 랭킹

수동으로 추가

개발자 도구 코드 없이, 제목/플랫폼/소장률만 입력해서 바로 추가할 수 있어요.

웹툰 불러오기

레진 북마클릿 실행 후 복사한 내용을 클립보드에서 바로 읽어와 자동으로 추가합니다. (붙여넣기 직접 안 해도 됨)
현재 모드: HTML 코드 (범용 파싱 → 실패 시 레진 전용 파싱으로 자동 폴백)

클라우드 동기화 (GitHub Gist)

최초 1회 PC에서 "새 동기화 시작"으로 Gist를 만든 뒤, 같은 토큰과 Gist ID를 폰에도 입력하면 됩니다.
두 기기에서 각자 다른 작품을 정리했다면 "불러오기(덮어쓰기)" 대신 "병합"을 사용하세요. 신규 작품은 추가되고, 같은 작품은 별점(더 높은 값)·키워드·메모·그룹·정주행 기록이 합쳐집니다.
